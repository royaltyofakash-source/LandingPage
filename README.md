I want you to redesign and significantly upgrade this landing page into a world-class, premium, high-converting SaaS/creator-style landing page.

The existing center "Old Way vs New Way" before/after image comparison slider is the CORE VISUAL of the page.

DO NOT REMOVE IT.

DO NOT REPLACE IT.

DO NOT TURN IT INTO A STATIC IMAGE.

DO NOT MOVE IT to another section.

DO NOT change its fundamental before/after slider behavior.

The center comparison image must remain visually centered and remain the hero visual of the page.

Everything else around it should be redesigned from scratch.

==================================================

1. OVERALL DESIGN DIRECTION

==================================================

Create a premium, highly polished, modern landing page with the visual quality of a top-tier startup / creator / education brand.

The design should feel:

- premium

- bold

- confident

- cinematic

- modern

- conversion-focused

- slightly editorial

- minimal but visually rich

- extremely polished

- NOT generic

- NOT template-looking

- NOT over-designed

Think:

Apple-level spacing + modern SaaS landing page quality + high-end creator marketing website + cinematic motion design.

Use strong typography, excellent whitespace, subtle borders, sophisticated shadows, micro-interactions and carefully controlled animations.

Do NOT make every element move constantly.

Animations should feel intentional and expensive.

==================================================

2. PRESERVE THE CENTER IMAGE SLIDER

==================================================

This is the most important requirement.

Keep the existing center comparison image exactly as the main visual:

"THE OLD WAY VS THE NEW WAY"

The before/after image slider must:

- remain horizontally centered

- remain in the main hero section

- remain approximately the same visual size

- preserve the draggable comparison divider

- preserve the before/after interaction

- preserve the image content

- preserve the rounded corners

- preserve the overall visual composition

You may improve the surrounding container, shadows, glow, border and animation.

Add a subtle premium entrance animation:

On page load:

1. image container fades in

2. slightly scales from 0.96 → 1

3. moves upward around 20px

4. divider softly animates into position

Do NOT animate the image continuously.

The slider should feel stable and premium after entering.

Add subtle hover behavior:

- very subtle elevation

- tiny scale increase such as 1.005–1.01

- slightly stronger shadow

Nothing exaggerated.

==================================================

3. REBUILD THE HERO SECTION

==================================================

The current hero feels too static.

Create a stronger visual hierarchy.

At the very top, keep a small announcement bar but redesign it as a premium announcement ticker.

Make it:

- dark/navy background

- tiny uppercase typography

- letter spacing

- subtle moving highlight

- thin bottom border

The ticker should move very slowly or have a subtle shimmer.

Do NOT make it distracting.

==================================================

4. HERO EYEBROW

==================================================

Create a premium pill above the headline:

"● FREE TRAINING · NO COST"

- glass / translucent white

- subtle border

- soft shadow

- slight blur

fade + slide up on entrance.

==================================================

Create a much stronger headline hierarchy.

"How To Make Money So Fast"

Use a large, heavy, modern sans-serif font.

The headline should have:

- tight line height

- strong letter spacing

- excellent responsive behavior

- maximum width around 800px

- centered alignment

Animation:

Reveal the headline line-by-line.

The main text should fade/slide upward.

The coral highlighted phrase should have a very subtle animated gradient/shimmer.

Do NOT use an aggressive flashing animation.

==================================================

6. SUBHEADLINE

==================================================

Replace the current paragraph with a cleaner hierarchy.

Use something similar to:

"100% halal. No face. No audience. No products."

Then a secondary sentence:

"The remote skill that took me from €11/hour to $10K/month — and helped 2,000+ brothers do the same."

Make the first sentence stronger/bolder.

Use muted gray for supporting text.

Animate this after the headline.

==================================================

7. HERO VISUAL SPACING

==================================================

Create a much more intentional transition from the headline into the comparison slider.

Add:

"THE OLD WAY VS THE NEW WAY"

Make this section feel like a product demonstration.

Use a small supporting caption:

"Drag to see the difference"

Do not use huge empty gaps.

Spacing must feel intentional and balanced.

==================================================

8. IMAGE SLIDER CONTAINER

==================================================

Wrap the existing slider inside a premium visual stage.

Add:

- very subtle shadow

- soft ambient glow behind it

- thin border

- rounded corners

- slight glass-like outer container

The glow should use the coral brand color very subtly.

Do NOT overpower the image.

The image itself must remain the focal point.

Add a very subtle floating depth effect when the user moves the mouse near the image.

Keep it extremely subtle.

==================================================

Do NOT make the entire countdown bounce.

==================================================

==================================================

This is extremely important.

Desktop:

- large hero typography

- maintain slider prominence

- adapt countdown

Mobile:

- slider remains centered

- never overflow horizontally

- headline scales cleanly

- CTA becomes full width

- countdown becomes a clean 2x2 grid

- social proof can stack vertically or remain compact

- announcement ticker remains readable

Do NOT simply shrink desktop.

Actually redesign spacing for mobile.

==================================================

==================================================

This page should feel extremely fast.

Do NOT use heavy effects that cause lag.

Prefer:

opacity

IntersectionObserver

requestAnimationFrame only when needed

The slider must remain smooth even on lower-end mobile devices.
